# Phase 1 Demo Recording Script

1. Open the landing page (http://localhost:3000).
2. Briefly highlight the app title and intro text.
3. Click the Start button to open /camera.
4. Show the webcam permission prompt and allow access.
5. Show the live camera feed and overlay.
6. Hold one hand in view; point out "1 hand detected" status.
7. Hold two hands in view; point out "2 hands detected" status.
8. Show the FPS value and status indicator.
9. Toggle English/Tagalog and read the placeholder transcript change.
10. Click Text-to-Speech to play the selected placeholder.

End with a short statement: "Phase 1 demonstrates the real-time camera pipeline and landmark preview."
