Animation Dataset Manager: retry on load failure, honest empty states

The initial fetch had no retry - a failed load left the page stuck on
a generic "Failed to load dataset" with no way to recover short of a
full page refresh. Extracted the fetch into loadDataset() and wired a
Retry button to it.

Empty state used to say "No matching assets found" whether there were
zero recordings at all or the search just didn't match anything -
distinguished the two so the message actually tells the admin what to
do next (record/upload vs. try a different search).
